== PHASE 0 — PLATFORM RESEARCH (2026-08-08) ==

Verify free tiers only from the provider's own page or the real signup flow.
  Blogs and "best free GPU" lists were wrong 3 times out of 3.

"No charge" is not "no card needed".
  A $0 authorization still blocks an account with no card.

Local model serving is impossible on 4-6GB VRAM / 8GB RAM.
  Weights alone eat it; the KV cache grows with prompt length.

Free credits are spent by machine uptime, not by typing time.
  Always stop a cloud machine when you stop working.

Lightning AI gives 5 credits once, not 15 per month.
  ~2 hours on an A100, ever. Not a resource to come back to.

ZeroGPU bills nothing while idle.
  That single property is what makes it right for serving a demo.

Eight platforms rejected for requiring a card.
  Written down so the research is never repeated.


== PHASE 1 — SYSTEM DESIGN ==

A walking skeleton finds integration bugs while they are still cheap.
  Thin end-to-end first, deep layers after.

Research can substitute for building.
  More browser tabs than commits is the warning sign.

Pick the orchestrator that stays provider-neutral.
  Single-vendor agent SDKs cannot host a multi-provider fallback chain.

One seam for all model access.
  Free endpoints vanish; a provider swap must be a one-file edit.

Quota sharing decides whether a fallback actually helps.
  Two tiers on one account pool both die together.

The tightest tier sizes the whole chain, not the largest.
  131K context is useless behind a 30K tokens/minute cap.

An empty answer is a failure, not an answer.
  Returning it makes a dead tier look healthy.

Model identity must cross the seam, not just reach the log.
  The log is for us; the return value is for the UI.

temperature 0 gives greedy decoding, not identical text.
  Never write an evaluation that assumes exact string equality.

Ask the user before spending money — one layer above the client.
  The client reports state; it never talks to the user.


== PHASE 2 — CODE DESIGN ==

Choose OOP or functions per case, never by habit.
  State + behaviour together = class. Pure transformation = function.

Never write an abstract base class with one implementation.
  Write the second one first, then extract what is really shared.

Variants that differ only in data are instances, not subclasses.
  Three providers, one class, three constant sets.

One module, one reason to change.
  Line count is a symptom to investigate, never the rule.

Contracts live alone and import nothing.
  This is what prevents circular imports.

__init__.py is the package's public API.
  Internals can then be renamed forever without breaking a caller.

Plan folders early, create files late.
  A placeholder module is a promise that rots.

Constants move out when a second consumer is scheduled, not written.
  Moving a constant is cheap; guessing an abstraction is not.

Not everything belongs in a config file.
  Varies by deploy = settings. Same everywhere = module constant.

Never name a module "utils".
  It becomes the file nobody dares to delete from.

Store the name of the env var, not the key.
  Reading at call time also makes CI injection work unchanged.

Keyword-only arguments guard the interface, not the internals.
  A bare number at a call site tells the reader nothing.

max_tokens belongs to the task, not to the model.
  A yes/no check needs 200 tokens; a full report needs 4,000.

Static input budget, dynamic output budget.
  One prompt for every tier is what keeps comparisons comparable.

A field nobody reads is dead code.
  Log token usage now; return it when the UI needs it.


== PHASE 3 — ERRORS AND TESTS ==

Handle a failure only where you can do something about it.
  Otherwise let it travel up to a layer that can.

Every except either recovers or re-raises as this layer's type.
  Always with `from exc`. Converting must not destroy the evidence.

A caller's bug and a provider's failure are different exceptions.
  ValueError must crash; LLMError must be caught by the loop.

An error message must carry the provider's own words.
  A bare "HTTP 400" is not a message.

An exception's payload is its type.
  Add fields only when a caller must branch on structured data.

Tests pin behaviour, not lines.
  Happy path, every failure branch, and the outside contract.

Mock at the boundary, never inside.
  Mocking your own function proves only that your mock works.

Fake the server, not requests.post.
  A hand-built fake response behaves unlike the real one.

parametrize for the same branch; separate tests for different branches.
  This is the line between sufficient and redundant.

Smoke tests prove the wire works, never that an answer is good.
  Quality is measured by evaluation, which is a score, not pass/fail.

Smoke tests must be opt-in.
  A test suite must not spend a 50/day pool.

Tests arrive with the layer they test.
  Unit now, API with FastAPI, integration with retrieval.


== PHASE 4 — TOOLING ==

One tool, one pinned version, three places.
  Editor, pre-commit, CI must never disagree about what is correct.

CI verifies; humans and hooks fix.
  Auto-fixing in CI hides the problem and needs write access.

pre-commit install is needed once per clone.
  Hooks live in .git/, which is never cloned or committed.

A hook that changes a file aborts the commit on purpose.
  You should see the change before it enters history.

Schedule one smoke run a week.
  Free models disappear silently; an email beats a blocked session.

Secrets live in GitHub Actions secrets, never in YAML.

.vscode/settings.json is committed; machine paths never are.


== PHASE 5 — VERIFIED NUMBERS (2026-08-10) ==

OpenRouter free: 20 requests/minute AND 50 requests/day.
  The per-minute cap was missed in the first read.

OpenRouter limits are global per account.
  Extra keys or accounts do not raise them.

Remaining free quota cannot be checked in advance.
  Only a 429 response carries the rate-limit headers.

A wrong model slug returns HTTP 400, not 404.

GET /api/v1/models lists text models only.
  Rerank and embedding models are separate categories on the site.

A claimed ":free" variant may not exist.
  Ling 3.0 Flash has none; only ling-3.0-tiny:free is free.
